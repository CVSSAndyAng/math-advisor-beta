# Scientific calculator update

Math Advisor now includes a built-in scientific calculator in:

- Analyse question entry
- Typed Algebra Check question entry
- Student working
- Offline practice working

Functions include:
- ordinary arithmetic
- powers
- square roots
- sin / cos / tan
- pi
- natural logarithm
- logarithms with a base
- previous answer recall

The calculator is intended for numerical checking and does not replace required written working.
