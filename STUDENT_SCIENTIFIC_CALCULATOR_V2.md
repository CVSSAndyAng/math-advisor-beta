# Student-only scientific calculator

The calculator is removed from all question-entry workflows.

It is available to students in:
- Analyse -> Student working
- Offline practice

The calculator is an original Math Advisor implementation with a conventional
scientific-calculator layout inspired by the feature set commonly found on online
scientific calculators.

Features:
- direct keyboard typing and clickable keypad
- DEG / RAD modes
- sin, cos, tan
- inverse sin, inverse cos, inverse tan
- pi and e
- arbitrary powers, square and cube
- square root and cube root
- natural log and base-10 log
- reciprocal and percentage
- factorial
- EXP / scientific notation
- Ans
- M+, M-, MR
- backspace, AC, +/- and rounding

It does not copy Calculator.net's JavaScript.
