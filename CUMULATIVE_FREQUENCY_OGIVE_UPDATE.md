# Cumulative Frequency / Ogive update

Cumulative-frequency questions now use a realistic monotone S-shaped profile.

Reference 100-student data:
(0,0), (20,5), (30,12), (40,27), (50,50), (60,73),
(70,88), (80,95), (90,98), (100,100).

The logistic idea is used only as a data-generation rationale. Students are not
expected to know the logistic formula unless modelling is explicitly assessed.

Offline Practice supports median, quartiles, IQR, percentiles, and threshold questions
and displays the deterministic ogive.

Paper Setter has a stricter cumulative-frequency contract so generated papers use:
- non-decreasing cumulative frequencies;
- final cumulative frequency equal to sample size;
- upper class boundaries/scores on the x-axis;
- cumulative frequency on the y-axis;
- a smooth monotone curve;
- completed graph only for graph-reading questions;
- blank construction grid/table when students must draw the curve.

The existing Word export embeds the rendered statistics graph as a PNG.
